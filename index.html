ABOUT THE PROJECT

Designed around farmer trust

KrishiMitra AI is a working prototype for accessible, multilingual farmer assistance.

What works in this prototype

Language toggle

Interface labels can switch between English and Hindi; the AI chatbot detects the language used in your message and replies in that language when supported.

Farmer chat

AI-powered multilingual farmer assistant: automatically detects the language and responds in the same language when Gemini is configured.

Live weather lookup

Uses Open-Meteo geocoding and forecast endpoints when internet access is available.

Transparent limits

Crop image analysis uses the configured AI model when available and provides preliminary observations, not a confirmed diagnosis.

Important limitations

Live AI chat and crop-image analysis require a valid Gemini API key in the backend .env file. Without it, the app falls back to demo responses. Scheme cards link to official portals but do not check personal eligibility. Weather depends on a third-party forecast service and an internet connection. Do not use this prototype as the sole basis for pesticide, medical, financial or legal decisions.
